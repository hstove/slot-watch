# Slot Watch UI

This package is part of the Slot Watch monorepo, and it's responsible for the frontend.

## Stack

- `bun` for package management and running things
- React
- Vite
- Tanstack Start
- Jotai for state management
- `@stadcn/ui`

## Memory

- Dev server: `https://slotwatch.localhost`
- Server logs: `tail -n 100 tmp/dev-server.log`
- UI design: See `./UI-DESIGN.md`
- Prod URL: `https://slotwatch.dev`
